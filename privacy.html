Privacy Policy

Effective Date: June 29, 2026

Last Updated: June 29, 2026

1. Data Collection

The GraveGardenBeat App does not collect, store, or transmit any personal data from TikTok users or any other individuals.

The App makes API calls to TikTok solely to:

  • Retrieve metrics (followers, video views, likes) for the owner's own account (@gravegardenbeat)
  • Upload and publish video content to the owner's own account

2. Authentication

The App uses TikTok OAuth 2.0 to obtain an access token for the owner's account. This token is stored locally on the owner's computer (in a .env file) and is never transmitted to any server other than TikTok's official API endpoints.

3. Third-Party Sharing

No data is shared. The App does not integrate with analytics services, ad networks, or any third-party data processors. All data stays on the owner's local machine.

4. Cookies & Tracking

The App does not use cookies, tracking pixels, or any form of user tracking.

5. Data Security

API credentials are stored in a local .env file secured by the operating system's file permissions (Linux, owner-read-only). The source code repository containing the App logic is separate from any credential storage.

6. Children's Data

The App is not directed at children and does not knowingly collect data from anyone under 13 years of age.

7. Changes to This Policy

If this policy changes, the updated version will be posted at this URL with a new "Last Updated" date.

8. Contact

For privacy-related questions, contact the App owner via the @gravegardenbeat TikTok account or through the GitHub repository hosting this page.
