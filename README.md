# GraveGardenBeat App

Personal tool for managing the [@gravegardenbeat](https://www.tiktok.com/@gravegardenbeat) TikTok creator account — auto-posting music beat previews and tracking analytics.

## What it does
- Upload and publish type beat previews (15-60 sec) to TikTok
- Fetch account metrics (followers, video views, likes)
- Runs locally on Linux, no third-party access
